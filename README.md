# Yorushika Setlist Maker / ヨルシカ セトリメーカー

## 使い方
1. `index.html` をブラウザで開きます。
2. 曲を選択します（最大20曲）。選んだ曲は順番を変更できます。
3. タイトル、サブタイトル、日付・メモ、背景や文字スタイルを調整します。
4. 「PNG画像を保存」でポスターを保存します。
5. ページ最下部の「利用規約」から利用規約・注意事項を確認できます。

## ファイル
- `index.html`: セトリメーカー本体
- `app.js`: 曲選択、プレビュー、PNG出力
- `style.css`: ページのスタイル
- `terms.html`: 日本語・英語の利用規約
- `ame.png`, `fumi.png`, `oreng.png`, `umi.png`, `sakura.png`: ポスター背景
- `ite_l.png`, `ite_r.png`: タイトル左右の装飾（元画像はTGAからPNGに変換）

すべてのファイルを同じフォルダーに置いて `index.html` を開いてください。
